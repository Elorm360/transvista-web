## Color Philosophy

Primary Blue

Used for:

- Primary CTA
- Links
- Active navigation
- Trust signals

Accent Orange

Used sparingly for:

- Highlights
- Featured elements
- Status accents
- Secondary CTAs

Neutral Colors

Support readability and create visual balance.

Success

Confirmation messages.

Warning

Attention states.

Destructive

Errors and destructive actions.

## Design Principles

1. Trust before beauty.
2. Clarity over complexity.
3. Mobile first.
4. Accessibility by default.
5. Consistency over novelty.
6. Performance is part of the user experience.
7. Authentic African storytelling.
8. Every interaction should reduce uncertainty.
